# EARWAX

An open-source Android music player whose whole interface is **3-D chrome hardware** instead of a normal UI:
a silver head whose forehead is the screen and whose speaker-pod "ears" are the buttons, floating shaped
popup windows (whale, orb) and a sculpted notification strip. Pure Java, no Kotlin, no Compose.

* Finds **every audio file on the phone** (MediaStore) and queues it.
* Plays in the background (foreground service + MediaSession: lock screen, Bluetooth, headset buttons).
* Real DSP: 10-band EQ, pre-amp, bass/treble shelves, mono L/R, spectrum analyser, independent pitch & speed.
* Floating popup over any app, drag it, turn the blue knob to change the current tool (volume, pitch, speed, bass, treble, sleep).
* Build in the cloud with GitHub Actions, nothing to install on the phone.

## Get the APK (no computer needed)
1. Create a GitHub repo and upload this whole folder (or `git push`).
2. Open the **Actions** tab, run **build-apk** (it also runs on every push).
3. Download the `earwax-apk` artifact, unzip, install `app-release.apk`.

First launch asks for: audio access, notifications, and (when you tap the `P` pearl) "display over other apps".

## Controls
| Where | What |
|---|---|
| Left ear (3 cones) | previous / play-pause / next |
| Right ear (3 cones) | library list / equalizer / sound FX panel |
| 4 pearls on the forehead | shuffle, repeat, sleep timer, popup (tap again: whale -> orb -> off) |
| Bottom of the screen | drag to seek |
| Popup: blue knob | drag up/down to change the selected tool; the wrench button picks the tool |
| Popup: LCD strip | drag to seek; drag the body to move the window |
| Notification | 3-D strip, buttons sit on the sculpture itself |

## Re-generating the artwork
All skins are generated by scripts (numpy + scipy + Pillow), so contributors can restyle everything:
```
pip install numpy scipy pillow matplotlib
cd tools
python3 head.py 1080 ../app/src/main/assets/skins/head.png ../app/src/main/assets/skins/head.json
python3 shapes.py ../app/src/main/assets/skins
python3 gen_layout.py      # notification layouts + icons
python3 preview.py         # writes a preview PNG from the same assets/layouts the app uses
```
See `ARCHITECTURE.md` for how the pieces fit. License: MIT.
